# RM — Global Investment Society Research

Repository for GIS Investment Research assignments and shared tooling.

## GIS pitch deck template

Reusable **22-slide** investment pitch template (python-pptx) for IR selection:

```bash
pip install python-pptx
cd GIS
python3 build_blank_template.py   # → GIS_Investment_Pitch_Template.pptx
```

See **[GIS/README.md](GIS/README.md)** for formatting rules, slide order, and how to build a new company deck.

**Reference example:** `GIS/GIS_Investment_Pitch_Template_Reference_LULU.pdf` (filled LULU pitch).
